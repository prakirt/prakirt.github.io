# Prakirt Raj Jhunjhunwala - Personal Website

This is my academic personal website featuring my research, publications, and contact information.

## How to Deploy on GitHub Pages

1. Create a new repository on GitHub named `<username>.github.io` (replace `<username>` with your GitHub username)
2. Clone the repository locally:
   ```bash
   git clone https://github.com/<username>/<username>.github.io.git
   cd <username>.github.io
   ```
3. Copy the `index.html` file from this directory
4. Push to GitHub:
   ```bash
   git add index.html
   git commit -m "Initial website commit"
   git push -u origin main
   ```
5. Your website will be live at `https://<username>.github.io`
